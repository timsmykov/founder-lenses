# Founder Lenses

Small, source-aware agent skills for examining concrete decisions through research from [Founder Systems](https://github.com/timsmykov/founder-systems).

## First skill: Necessity before automation

Before automating a process, identify what it achieves, which steps are necessary and what failure would cost. Then compare a bounded automation with simpler and manual alternatives.

- [Read the skill](skills/necessity-before-automation/SKILL.md)
- [See two synthetic examples](examples/necessity-before-automation.md) · [Read a public-workflow assessment](examples/public-workflow.md)
- [Source and attribution](SOURCES.md)

The skill combines source-informed questions into an editorial procedure; it is not a founder persona or a validated formula. Sources, interpretations and assumptions are kept distinct. No private research archives or full source texts are included.

To use it, copy the skill folder into your agent's skills directory and ask it to evaluate a concrete workflow. It recommends next steps; it does not authorize changing a live system.
